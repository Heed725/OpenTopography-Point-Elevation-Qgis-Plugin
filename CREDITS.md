# Credits and attribution

## OpenTopography

This plugin queries the OpenTopography Point Elevation API:

- https://opentopography.org/
- https://portal.opentopography.org/apidocs/#/Public/getPointElevation

OpenTopography data products have their own dataset licenses and citation guidance. Users should cite the dataset(s) they use as required by OpenTopography and the original data provider.

## QGIS plugin inspiration

The plugin concept and QGIS/OpenTopography integration were inspired by:

**OpenTopography DEM Downloader QGIS plugin**  
Author: **Kyaw Naing Win**  
Repository: https://github.com/knwin/OpenTopography-DEM-Downloader-qgis-plugin

That plugin is designed to download DEM rasters for a user-defined extent. **OpenTopography Point Elevation** is a separate implementation focused on the newer point elevation endpoint, attribute enrichment, map clicks and Processing point workflows.
