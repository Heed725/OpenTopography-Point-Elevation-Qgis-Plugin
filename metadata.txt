about=OpenTopography Point Elevation uses the OpenTopography Point Elevation API to query an elevation for a WGS84 coordinate from a selectable global or regional elevation dataset. It can enrich an existing point layer's attribute table, create new elevation points from typed coordinates, or create points by clicking the map. The API-reported vertical CRS EPSG and unit can be stored with each result. Inspired by and credited to the OpenTopography DEM Downloader QGIS plugin by Kyaw Naing Win, while implemented as a separate point-elevation workflow.
